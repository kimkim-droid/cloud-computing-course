# Google Cloud Platform (GCP) Research

## 1. Brief Overview

Google Cloud Platform (GCP), also known as Google Cloud, is a cloud computing platform that provides services for computing, storage, networking, databases, data analytics, artificial intelligence, machine learning, and application development. Organizations can use Google Cloud to build, deploy, and manage applications and infrastructure using Google's global cloud infrastructure.

## 2. Global Infrastructure

Google Cloud organizes its infrastructure into regions and zones. A region is an independent geographic area that contains multiple zones. Zones are separate deployment areas within a region and are designed to provide isolation from many types of infrastructure failures.

Google Cloud has infrastructure locations across North America, South America, Europe, Asia, the Middle East, and Australia. Organizations can choose regions and zones based on requirements such as latency, availability, data location, and durability. Deploying resources across multiple zones or regions can help improve application resilience.

## 3. Cloud Management Console

The Google Cloud Console is a web-based interface used to create, manage, and monitor Google Cloud resources and services. Users can manage projects, virtual machines, storage, databases, networks, security settings, and other cloud resources through the console.

Google Cloud also provides tools such as the Google Cloud CLI and APIs for users who prefer command-line or programmatic management.

## 4. Four Core Google Cloud Services

### Compute Engine

Compute Engine provides virtual machines that run on Google's infrastructure. Organizations can use Compute Engine to run applications, websites, and other workloads that require virtual servers.

### Cloud Storage

Cloud Storage is an object storage service used to store and retrieve data. It can be used for backups, application data, media files, archives, and other types of unstructured data.

### Cloud SQL

Cloud SQL is a fully managed relational database service. It supports database engines including MySQL, PostgreSQL, and SQL Server, allowing organizations to use relational databases without managing all of the underlying infrastructure themselves.

### Virtual Private Cloud (VPC)

Google Cloud VPC provides networking functionality for Compute Engine virtual machines, Google Kubernetes Engine clusters, and serverless workloads. VPC networks are global resources with regional subnets and provide scalable and flexible networking for Google Cloud resources.

## 5. Three Advantages of Google Cloud

1. **Strong AI and machine learning capabilities** – Google Cloud provides a wide range of services and tools for developing and deploying artificial intelligence and machine learning applications.

2. **Global network and infrastructure** – Google Cloud operates infrastructure across multiple continents and provides regions and zones that organizations can use to design applications for performance and availability.

3. **Strong data and analytics capabilities** – Google Cloud provides services for data processing, analytics, storage, and machine learning, making it useful for organizations that work with large amounts of data.

## 6. Typical Enterprise Use Cases

Google Cloud can be used by enterprises for application hosting, data storage, database management, data analytics, artificial intelligence, machine learning, and containerized application deployment.

Organizations can also use Google Kubernetes Engine (GKE) to deploy and manage containerized applications. Google Cloud's global infrastructure can support applications that need high availability, scalability, and low latency.
