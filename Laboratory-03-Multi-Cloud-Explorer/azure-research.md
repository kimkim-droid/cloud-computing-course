# Azure Research

## 1. Brief Overview

Microsoft Azure is a cloud computing platform that provides services for computing, storage, networking, databases, analytics, artificial intelligence, and application development. Organizations can use Azure to build, deploy, manage, and scale applications and IT infrastructure through Microsoft's global cloud platform.

## 2. Global Infrastructure

Azure has a large global infrastructure with more than 80 regions and more than 500 datacenters. Azure regions are geographic areas where organizations can deploy cloud resources. Azure also provides Availability Zones, which are physically separate locations within an Azure region designed to help protect applications from datacenter-level failures.

Azure's global infrastructure helps organizations meet requirements for low latency, data residency, availability, and business continuity.

## 3. Cloud Management Console

The Azure portal is a web-based management console used to create, manage, and monitor Azure resources. Through the portal, users can create virtual machines, databases, storage resources, and networks. The portal also provides tools for monitoring resources, managing subscriptions, viewing costs, and accessing Azure services through a graphical interface.

## 4. Four Core Azure Services

### Azure Virtual Machines

Azure Virtual Machines provides scalable virtual computing resources in the cloud. Organizations can use virtual machines to run Windows or Linux operating systems and applications without purchasing and maintaining physical servers.

### Azure Blob Storage

Azure Blob Storage is an object storage service designed to store large amounts of unstructured data. It can be used for documents, images, videos, backups, logs, and application data.

### Azure SQL Database

Azure SQL Database is a fully managed relational database service based on Microsoft SQL Server. It helps organizations run databases in the cloud while Azure handles many management tasks such as infrastructure maintenance and updates.

### Azure Virtual Network

Azure Virtual Network provides a private network environment for Azure resources. It allows virtual machines and other Azure services to communicate with each other, the internet, and on-premises networks while providing network isolation and security controls.

## 5. Three Advantages of Azure

1. **Strong Microsoft integration** – Azure integrates closely with Microsoft technologies such as Windows Server, Active Directory, Microsoft 365, and SQL Server, making it a suitable choice for organizations already using Microsoft's ecosystem.

2. **Global infrastructure** – Azure provides a large number of regions and datacenters around the world, helping organizations deploy applications close to their users and meet data residency requirements.

3. **Wide range of cloud services** – Azure provides services for computing, storage, databases, networking, artificial intelligence, analytics, security, and application development.

## 6. Typical Enterprise Use Cases

Azure is commonly used by enterprises for hosting business applications, migrating Windows Server workloads, running databases, storing organizational data, creating virtual networks, and developing cloud applications.

Organizations can also use Azure for artificial intelligence, data analytics, hybrid cloud environments, backup and disaster recovery, and modern application development.
