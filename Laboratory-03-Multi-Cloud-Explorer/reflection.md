# Mission Reflection

## Mission 3 Reflection

After exploring AWS, Microsoft Azure, and Google Cloud Platform, the cloud platform that impressed me the most was Google Cloud Platform. I found its strengths in artificial intelligence, machine learning, data analytics, and Kubernetes especially interesting. These technologies are useful for modern applications and can support organizations that need powerful and scalable cloud solutions.

AWS, Azure, and GCP have many similarities. All three provide computing, storage, networking, databases, identity management, and other cloud services. They also use global infrastructure with regions and other infrastructure locations to help organizations deploy applications with good availability and performance. Although the services have different names, many of them provide similar functions.

Business requirements have an important influence on cloud platform selection. A company should consider its budget, existing technology, workload, scalability, security, location, and future plans before choosing a provider. For example, Azure is a good choice for an organization that already uses Microsoft technologies, while Google Cloud can be a strong option for AI and machine learning workloads.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. The best choice depends on the specific problem that the organization needs to solve. I learned how to compare cloud services and connect technical features with different business requirements.

My GitHub Cloud Computing Portfolio has also improved after completing this mission. I organized my work into a dedicated Laboratory-03-Multi-Cloud-Explorer folder and created separate Markdown files for AWS, Azure, GCP, comparisons, and client recommendations. This activity helped me practice technical documentation, cloud platform comparison, and making technology recommendations based on business needs.
