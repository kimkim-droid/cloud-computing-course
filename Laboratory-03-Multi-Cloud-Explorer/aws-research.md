# AWS Research

## 1. Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides a wide range of infrastructure and technology services over the internet. Organizations can use AWS to run applications, store data, build databases, create networks, and develop modern cloud-based solutions without maintaining all of the physical infrastructure themselves.

## 2. Global Infrastructure

AWS operates a global infrastructure made up of geographic Regions and Availability Zones. An AWS Region is a separate geographic area, while Availability Zones are isolated locations within a Region. AWS states that its cloud spans 39 geographic Regions and 123 Availability Zones as of 2026. This infrastructure helps organizations design applications for high availability, fault tolerance, and lower network latency by selecting appropriate Regions and using multiple Availability Zones.

## 3. Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Through the console, users can create and manage cloud resources, select AWS Regions, monitor service usage, manage users, view billing information, and access many AWS services from one interface.

## 4. Four Core AWS Services

### Amazon EC2

Amazon Elastic Compute Cloud (Amazon EC2) provides resizable computing capacity in the AWS Cloud. It allows organizations to run virtual servers and select computing resources according to their workload requirements.

### Amazon S3

Amazon Simple Storage Service (Amazon S3) is an object storage service used to store and retrieve data. It can be used for backups, application data, websites, data lakes, and other storage needs.

### Amazon RDS

Amazon Relational Database Service (Amazon RDS) is a managed relational database service. It helps organizations set up, operate, back up, patch, and scale relational databases without managing all of the underlying database infrastructure themselves.

### Amazon VPC

Amazon Virtual Private Cloud (Amazon VPC) allows users to create a logically isolated virtual network in AWS. Users can configure IP address ranges, subnets, routing, and network security for their cloud resources.

## 5. Three Advantages of AWS

1. **Global infrastructure** – AWS provides Regions and Availability Zones around the world, allowing organizations to deploy applications closer to their users and design highly available systems.

2. **Wide range of services** – AWS provides many services for computing, storage, databases, networking, security, analytics, and other cloud requirements.

3. **Scalability and flexibility** – Organizations can increase or decrease cloud resources according to their workload requirements instead of maintaining fixed physical infrastructure.

## 6. Typical Enterprise Use Cases

AWS can be used by enterprises for many different workloads. Common examples include hosting websites and business applications, storing and backing up large amounts of data, running relational databases, developing and deploying applications, supporting data analytics, and building artificial intelligence and machine learning solutions.

AWS is also suitable for organizations that need highly available applications because workloads can be distributed across multiple Availability Zones and Regions when appropriate.
