# Reflection

## My Learning Experience

This laboratory activity helped me understand the basic skills needed to work in a cloud-based Linux environment. I learned how to access and use Ubuntu through the KillerCoda Playground and how to create and log in to a new Linux user account.

I also learned how to use Linux commands to check system information, including the Linux distribution, kernel version, CPU information, memory, and available disk space. I practiced organizing files and directories and creating Markdown files for technical documentation.

Another important lesson I learned was how GitHub can be used to organize and maintain a cloud computing portfolio. Creating the repository and preparing the required files helped me understand the importance of proper documentation and version control.

Overall, this laboratory gave me practical experience with Linux, cloud environments, Markdown, and GitHub. These skills will be useful as I continue learning about cloud computing and other cloud technologies throughout the semester.
